# Preview da biblioteca de produtos — layout premium

Visual inspirado no mockup aprovado pelo usuário, com capturas **reais** das LPs (3 screenshots por produto se houver). Cards de produtos exibem dados de contagem ativos/inativos da planilha em tempo real, sem números fictícios e sem serviços extras.

A prévia mantém a lógica de busca, navegação para LPs, filtros por LP, detalhes e atualização. Ações de escrita via editor estão desabilitadas nesta prévia por segurança.

O site publicado em ../ continua inalterado durante homologação da interface.
